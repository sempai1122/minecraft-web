System Design Notes

  • WebSocket-style event bus with message ACKs.
  • Ordered delivery using per-chat sequence IDs.
  • Read receipts: delivered → seen.
  • REST-style fetch mocked for history/profile loading.
  • Rate limiting and basic moderation checks.

This browser demo simulates server behavior and can be backed by Node.js + Socket.io + MongoDB/PostgreSQL in production.
